**[K-Lite Codec Pack Standard](https://codecguide.com/download_k-lite_codec_pack_standard.htm)** is a lightweight yet powerful collection of tools designed for flawless multimedia playback. The package includes the legendary **MPC-HC** player and all the essential codecs needed to support a wide variety of audio and video formats.

---

### ✨ Key Features
* **MPC-HC Player:** Classic, lightning-fast, and user-friendly media player included out of the box.
* **Universal Compatibility:** Plays almost any multimedia file format.
* **Lightweight:** Low system resource consumption and small footprint.

### 💻 Quick Installation via Chocolatey

You can install this package with a single command. Open your Command Prompt (`cmd`) or `PowerShell` as Administrator and run:

```powershell
choco install k-litecodecpack-standard
```
